# 路线图 / Roadmap

> 欢迎在 Issues 里讨论优先级。勾选项表示已完成。
> Discuss priorities in Issues. Checked items are done.

## 近期（v1.x）

- [x] 实时逐句翻译（DeepSeek / 本地 LM Studio 可切换）
- [x] 屏幕框选识别区域 + 常驻浅色区域提示框
- [x] 置顶悬浮层（点击穿透 / 可拖动 / 字号宽度可调 / 自动避开识别区）
- [x] 批量录制 → 整段翻译（均分分块 + 并发 + 推理强度可调）
- [x] 本地翻译记忆库（按游戏隔离 / 同句合一行 / 精确命中秒显 / 疑似命中确认）
- [x] 术语表（按游戏，`原文 → 译文 #备注`）
- [x] 历史 / 记忆库导出（JSON / TXT）
- [ ] **多语种（目标语言）测试**：系统化验证 en→zh、ja→zh、ko→zh 等组合的 OCR 与翻译质量
- [ ] **多语种（源语言）OCR**：除英文外支持日文 / 韩文 OCR 语言包与对应界面提示
- [ ] **界面多语言（i18n）**：抽出文案表，先补 English，再支持更多 UI 语言
- [ ] 打包发布：`electron-builder` 便携版与安装包，挂到 Releases
- [ ] 更多截图 / GIF 演示，降低上手门槛

## 中期

- [ ] 多显示器 / 多识别框支持（当前仅主显示器、单识别框）
- [ ] 悬浮层直接覆盖在原文字幕上（需 `Windows.Graphics.Capture`，避免把自己的像素截进 OCR）
- [ ] 翻译记忆库分片或迁移到 SQLite（面向数十万句量级）
- [ ] 批量翻译的失败块"按缺失索引补发"优化（进一步省 API）
- [ ] 术语表批量导入导出（CSV / JSON）

## 长期 / 探索

- [ ] 可插拔翻译源（更多 OpenAI 兼容端点、本地其他推理服务）
- [ ] 剧情脚本级导出（按章节导出对照译文）
- [ ] 缓存共享 / 同步（可选，默认仍纯本地）

## 非目标（明确不做）

- 不做任何形式的历史 / 译文上传（隐私优先，保持纯本地）
- 不内置任何 API Key 或代理服务
