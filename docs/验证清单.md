# 手动验收清单（真实屏幕 OCR）

自动化自测（`npm test`）覆盖了数据层、批量对齐、路由决策、提示词等**纯逻辑**部分。
唯一必须在**真实桌面**验证的是「真实游戏画面 → 屏幕 OCR 抓字」。按下面清单走一遍即可确认整体可用。

## 前置
- 已安装英文 OCR 语言包：Windows「设置 → 时间和语言 → 语言和区域」中有 **English (United States)**（多数中文系统自带）。
- 准备一个会显示英文对白 / 剧情的界面（游戏或网页均可），放在**主显示器**上。

## 1. 启动
双击项目根目录的 `启动.cmd`；或命令行 `npm install && npm start`。

## 2. 基础自测（确认环境没坏）
```powershell
npm test
```
应输出全部 `RESULT: N passed, 0 failed`。

## 3. 界面设置
- 游戏名称：随意（如 `Test`）。
- 翻译源与 API Key：选 ☁️ DeepSeek 并填入 Key（或切换 🔌 LM Studio）。
- 目标语言：`Simplified Chinese`。
- **识别区域**：点「🖱 框选区域」→ 屏幕上拖拽框住对白文字区 → 松开后自动回填 X/Y/W/H（Esc 取消）。也可手改数字。
- OCR 间隔 300ms、稳定帧数 3。

## 4. 真实 OCR 抓字
1. 让某句英文对白稳定显示在屏幕上。
2. 点「🔍 测试识别」→ 看下方输出是否为那行文字（而非空 / 乱码）。
   - 空 → 区域没对准，或缺少 OCR 语言包。
   - 乱码 → 框到了非文字区域（贴图 / 界面框），或当前是中文页面。
3. 点「▶ 开始 OCR」，让对白切换 2~3 句 → 观察顶部状态与底部日志是否逐句识别；主界面还会实时显示 OCR 当前看到的原文，便于对准。

## 5. 批量录制 → 整段翻译
1. 右上切到 **批量录制**。
2. 点「▶ 开始 OCR」（会自动进入收句）。
3. 让剧情连续播放 → 左侧「批量录制」显示已收句数，清单逐句列出（每行可 ✎ 编辑 / ✕ 删除，用于修正 OCR 误识）。
4. 点「⏹ 停止 OCR」冻结清单。
5. 点「整段翻译」→ 观察分块进度 → 完成后日志显示 `ok / totalLines`。
6. 切到右侧 **翻译记忆库**：确认已入库，且**译文不是原文回显**（若整段仍是英文原样，属异常）。

## 6. 实时命中
1. 切回 **实时逐句翻译** 模式。
2. 让刚才某句原文**再次出现** → 应**瞬间**显示已存译文，不再等待翻译、不重复调 API（历史该行「出现次数 +1」，不新增行）。

## 7. 术语表与悬浮层
- 在「悬浮层」区下方给当前游戏加一条术语（如 `Elden → 艾尔登 #地名`），再翻译含该词的句子，确认译名被采用。
- 悬浮层：确认可拖动（取消"点击穿透"后）、位置在内容更新时不跳回默认角、字号与宽度改动即时生效、不遮挡识别区域。
